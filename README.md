# Syty Kotek

Next.js standalone website and lead form for homemade lunch delivery in Pruszków, Poland.

The application is in [`site`](site/README.md). On Vercel set **Root Directory = `site`**.

Live site: https://syty-kotek.vercel.app

Vercel project: `livenapps/syty-mruczek`. Pushes to `codex/launch` automatically deploy to production. Builds run form-validation tests before compiling Next.js. Leads are stored in the private `restaurant` schema; email notifications remain a placeholder.
